# Product naming

Status: **Accepted**

The assistant is named **Franky**. The working folder and Git repository are named `franky`.

The name is used consistently across the control board, computer runtime, firmware identity, documentation, and repository-facing paths. Generic technical terms such as “assistant,” “runtime,” and “audio” remain where they describe a responsibility rather than the product identity.

Future wake-word candidates remain **“Yo Franky”** and **“Franky.”** Wake-word implementation and false-activation testing are separate decisions from the product name.
